Как пользоваться

Клик по карте — новая точка. Точку можно перетащить. Клик по точке выбирает её (на ней «−»), второй клик удаляет. Правый клик по точке удаляет сразу. «+» в середине отрезка вставляет точку. Магнит берёт дороги, видимые на экране: приблизьте карту.
